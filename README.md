# MangaBuff AutoDaily 🤖✨
### *Ваш персональный бот для автоматического чтения манги на MangaBuff*
Вся актуальная информация публикуется на канале https://t.me/mangaBuffBotSupport

**Автоматизированное решение для прокачки аккаунта на MangaBuff**  
_Идеально подходит для тех, кто хочет экономить время!_


## Системные требования
 - JDK version: 21.
 - Google Chrome последней версии.
 - 4 GB RAM

## Инструкция по применению и использованию:
 1. Скачиваем последнюю версию тут https://github.com/NikitaKuby/MangaBuffAutoDaily/releases
 2. Желательно переместить скачанный .exe файл в отдельную папку, где будет располагаться программа (например в папку "name" на рабочем столе). 
 3. Запустить программу и подождать, когда запуститься.
 4. Предзагрузить мангу (кнопка 3 на фото 1) ВАЖНО!!! (В целях безопасности используйте 3буквы(Прокси, впн), когда загружаете её, при скрапинге можно вполне легко получить бан по IP, кто-то ловит, кто-то нет, но не рискуйте, просто используйте любой, чтобы забанили не родной айпишник, а то придётся провайдеру звонить, просить поменять, дождаться когда она станет зеленной <img width="24" height="24" alt="image" src="https://github.com/user-attachments/assets/f4d6265e-84ee-43b5-968f-29edcfdd2d19" />
 5. После добавляем аккаунты (Кнопка 1 на фото 1).
 6. После добавления аккаунтов - можем приступать к работе.
 7. Ну и не забываем наводиться на GIF в нижнем правом углу экрана

P.S. В случае скачивания новой версии - новый экзешник поместите вместо старого, в таком случае переход пройдёт бесшовно 
 
## Фото 1, настройки
   <img width="405" height="359" alt="image" src="https://github.com/user-attachments/assets/3952cfa5-399b-4fc6-81d8-a25e707e4c8f" />

1. Кнопка добавления аккаунта
2. Чекбокс для отображжения браузера при работе бота (Для периодического чтения и/или работы бота), по дефолту hedles режим, при активном чекбоксе - браузеры отобрааются пользователю
3. Предзагружаем мангу, без этого манга не будет читаться.
4. Сбрасывает предзагруженную мангу, (MB что то удаляет, что то добавляет на сайт, поэтому рекомендую раз в месяцок проводить сброс и новю загрузку)
5. Кнопка для открыти настреок потоков, для слабых ПК (ноутов) можно выставить 1/1 или 2/2, тогда работа будет стабильнее и меньше нагружать комп, так же рекомендация: Если у вас 1-5 аккаунтов, то выставите 1/1, если 6-10, то выставите 2/2

## Фото 2, управление ботом
   <img width="302" height="346" alt="image" src="https://github.com/user-attachments/assets/216e3aa7-3336-4bed-b1ad-a02baacae599" />

6. Обновляет прогресс аккаунта, (Парсит с сайта информацию о аккаунте
7. Включаем отдельном 1 потоке сбор алмазов счата (раз в 15 минут собираем алмазик с чата у всех аккаунтов)
8. Запускает все выбранные задачи (выбранные = у которых включены чекбоксы): Просмотр рекламы, кликер шахты, прохождене квиза, оставление комментариев, прочитывание манги.
9. Читает периодически мангу, раз в час запускается и читает по 5~ глав манги у каждого аккаунта (Для сбора карт)
